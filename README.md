# Uber Website Redesign

## Thiranex UX/UI Design Internship

This project is a redesigned version of the Uber website created as part of the Thiranex UX/UI Design Internship.

## Project Overview

The goal of this project was to redesign the Uber website with a cleaner and more modern user interface while improving the overall visual structure and user experience.

## Design Process

- Studied the existing Uber website
- Identified areas that could be improved
- Created a redesigned website interface
- Focused on layout, visual hierarchy and usability
- Created the design and prototype in Figma
- Used the Builder.io Figma plugin during the design process

## Tools Used

- Figma
- Builder.io
- GitHub
